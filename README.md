# Valtrey Content

Модуль с контентом для авторского сеттинга **Вальтрей** (Foundry VTT).
   
## Что включено
   
- НПЦ и существа Вальтрея
- Предметы и артефакты
- Заметки журнала о мире
   
## Установка
   
В Foundry VTT:
1. Перейди в "Add-on Modules"
2. Нажми "Install Module"
3. Вставь ссылку манифеста:
```
https://raw.githubusercontent.com/твой-username/valtrey-content/main/module.json
```
4. Нажми "Install"
   
## Сеттинг Вальтрей
   
Тёмное фэнтези с элементами космического хоррора.
